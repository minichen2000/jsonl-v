# Building jsonl-v

English | [简体中文](BUILDING.zh-CN.md)

Build jsonl-v from scratch on a fresh machine.

## Artifact

A single exe file (about 4.5MB on Windows) with **no runtime dependencies**:
no .NET, no VC++ runtime, no Java, nothing to install — copy the exe and double-click to use it.

## The only prerequisite: the Rust toolchain

Only Rust (stable) is needed to build:

```powershell
# Windows (pick one)
winget install Rustlang.Rustup
# or download and run rustup-init.exe from https://rustup.rs

rustup default stable
```

> On Windows rustc uses the MSVC linker by default, which requires Visual Studio Build Tools
> (select the "Desktop development with C++" workload). rustup warns during installation if it is missing.
>
> Embedding the exe icon requires `rc.exe` from the Windows SDK (installed together with the Build Tools above).
> Without rc.exe the build fails at the icon step; in that case just move `assets/icon.ico` away to skip it
> (`build.rs` detects the missing icon file and skips automatically; program functionality is unaffected).

## Build

```bash
git clone <repo-url> jsonl-v   # or just copy the source directory over
cd jsonl-v
cargo build --release
```

Output: `target/release/jsonl-v.exe`

> If crates.io downloads time out on mainland China networks: the repo ships with `.cargo/config.toml`
> preconfigured with the rsproxy mirror, ready to use out of the box. Delete it if your network is good.

## Rust dependencies (downloaded automatically by cargo, no manual install)

| Dependency | Purpose |
|---|---|
| eframe / egui 0.31 | GUI framework (pure Rust, no system dependencies) |
| serde_json 1 | JSON parsing |
| memchr 2 | SIMD-accelerated line splitting |
| rfd 0.15 | Native file open dialog |
| sys-locale 0.3 | System locale detection (decides the default UI language) |
| embed-resource 2 (build-time, Windows only) | Embeds assets/icon.ico into the exe |

No DLLs or external commands are needed at runtime (the Explorer context-menu feature calls the system
built-in reg.exe; the app works fine without using it).

## Other useful commands

```bash
cargo test                        # 37 unit tests
cargo test -- --ignored           # additionally run the 100MB large-file performance test
cargo run -- docs/wire.jsonl      # run the debug build and open the sample
cargo run --example make_icon     # regenerate assets/icon.ico (after changing the icon)
```

## Cross-platform

The same code builds directly with `cargo build --release` on macOS / Linux:
- The CJK font fallback list already covers common Linux/macOS paths
- Explorer context-menu registration is Windows-only; on other platforms it degrades to an unavailable notice
- exe icon embedding only takes effect on Windows

## Directory structure

```
jsonl-v/
├── Cargo.toml
├── README.md           # user guide (English)
├── README.zh-CN.md     # user guide (Chinese)
├── BUILDING.md         # this document
├── BUILDING.zh-CN.md   # build guide (Chinese)
├── build.rs            # Windows only: embeds the exe icon
├── assets/
│   ├── icon.rc         # resource script
│   └── icon.ico        # generated by examples/make_icon.rs
├── docs/
│   ├── jsonl-viewer-spec.md  # original development spec
│   └── wire.jsonl            # test sample
├── examples/make_icon.rs # icon generator
└── src/
    ├── main.rs         # entry point: window, icon, CJK font loading
    ├── app.rs          # UI state machine: menus / three-pane layout / shortcuts
    ├── document.rs     # JSONL line index + lazy parsing + LRU cache
    ├── json_tree.rs    # collapsible JSON tree rendering
    ├── text_view.rs    # unescaped long-text viewer window
    ├── search.rs       # background-thread full-text search
    ├── wire.rs         # wire.jsonl enhancements (timeline / context rebuild / coloring)
    ├── settings.rs     # settings & recent files persistence
    ├── shell_menu.rs   # Explorer context-menu registration (Windows)
    ├── lang.rs         # Chinese/English UI strings
    └── icon.rs         # program icon pixel rendering
```
